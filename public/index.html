¿En qué se usan las consultas de hoy?

Ver tabla por día

Cuenta las consultas que hace la plataforma desde GitHub (incluidos los reintentos), por día en hora de Chile. No incluye consultas hechas con el mismo ticket desde otros lugares, como tu navegador. El límite de referencia es de 10.000 diarias por ticket; si se superara, ese día dejarían de llegar datos nuevos hasta el día siguiente.

Estado del sistema

El sitio se actualiza solo cada 15 minutos mediante GitHub Actions; GitHub puede atrasar algunas ejecuciones. Cuando un organismo le emite a tu empresa una orden de compra de Compra Ágil, el aviso llega por los canales activos.

El botón Actualizar ahora busca en el momento las Compras Ágiles y órdenes de compra nuevas; tarda entre 1 y 3 minutos y el listado se recarga solo al terminar. Con el sitio abierto, los datos nuevos de las actualizaciones automáticas también aparecen solos (se revisa cada 2 minutos).

Para enviar un mensaje de prueba: en GitHub, pestaña Actions → Actualizar Compras Ágiles → Run workflow.

Los datos del sitio están cifrados: solo se pueden leer después de ingresar con un usuario y clave válidos.
