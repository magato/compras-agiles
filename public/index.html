Estado del sistema

El sitio se actualiza solo cada 15 minutos mediante GitHub Actions; GitHub puede atrasar algunas ejecuciones. Cuando un organismo le emite a tu empresa una orden de compra de Compra Ágil, el aviso llega por los canales activos.

Para enviar un mensaje de prueba o forzar una actualización: botón Actualizar ahora → Run workflow (requiere tu sesión de GitHub).

Los datos del sitio están cifrados: solo se pueden leer después de ingresar con un usuario y clave válidos.
